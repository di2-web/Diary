# 📘 WaveLog (ウェーブログ) - 手帳AI日記 ＆ スキマログ

日常の何気ないつぶやきや写真、ボイスメモ、気分の変化（スキマログ）を記録するだけで、Gemini AI が自動的に温かみのある手帳風の日記を生成してくれるライフログ＆コミュニティ日記アプリケーションです。

---

## ✨ 主な特徴と機能

### 1. 💬 きょうの記録（スキマログ投稿）
- **手軽なリアルタイム投稿**: テキスト、写真添付、マイク録音（音声メモ）に対応。
- **気分の記録**: その時の気分（感情）をあわせて記録。
- **保護（ピン留め）機能**: 大切な記録はピン留めして保護できます。

### 2. 🪄 AIによる自動手帳日記生成
- **1日の記録を凝縮**: 「日記を作成」ボタン（中央のスパークルボタン）を押すだけで、今日のつぶやきからタイトル・本文・要約・カバー画像プロンプト・AIからの振返りコメントを全自動生成。
- **選べる執筆スタイル**: 「文学的」「ポップ」「ほのぼの」「感動的」など、気分に合わせたテイストで作成可能。

### 3. 🎨 手帳デコパレット (フォント ＆ 自由配置スタンプ)
- **フォント切り替え**: 明朝体、手書き風、丸ゴシック、ゴシック体などから好みの書体を選択。
- **スタンプツールバー**: ツールバーから好きな絵文字スタンプ（💮, 🌸, ☕️, 🌟, 👊, ☀️, 🌧️, 🎵, 🍰, 📌, 🎀, 🐾 など）を選択し、**手帳の好きな場所をタップ・クリックして自由にスタンプ**を押すことができます。

### 4. 🔓 ワンタップで公開 / 非公開を切り替え
- 最初は自分だけで楽しむ「非公開」にしておき、後から「みんなの誌」へ共有したい場合も、**日記の「非公開/公開中」バッジをタップするだけでいつでも切り替え可能**です。

### 5. 🌏 みんなの誌（SNSタイムライン）＆ 絵文字リアクション
- 他のユーザーが公開した手帳日記を閲覧。
- シンプルで心温まる**絵文字のみのリアクション**（❤️, 🌟, ☕, 🫂）で気軽に「スキ」や「ほっこり」を伝え合えます。

### 6. 🌊 気分の波 (Wave Canvas)
- 1日の中で変化した気分や感情のグラデーションを、美しく滑らかなインタラクティブな波のグラフで可視化します。

### 7. 📅 カレンダー ＆ 検索機能
- 過去の日記をカレンダー形式で一覧表示。キーワード検索機能で大切な思い出をすぐに見つけ出せます。

## 📖 使い方ガイド

```text
【STEP 1】「きょうの記録」につぶやきを投稿する
  ├ 画面下部またはメニューの「今日の記録」タブを開きます。
  ├ 今あったこと、思ったこと、写真や音声メモを気軽に投稿します。
  └ 何回でも投函してOK！

【STEP 2】AIで手帳日記を生成する
  ├ 画面中央の丸い「✨（スパークル）ボタン」またはヘッダーの「日記を作成」をタップ。
  ├ お好みのトーン（例: ほのぼの、文学的など）を選び「日記を作成する」をクリック。
  └ Gemini AI があなたのつぶやきを紡いで、素敵な日記を作成してくれます。

【STEP 3】手帳をデコレーションする
  ├ 作成された日記の「🎨 デコ」ボタンをタップ。
  ├ ① フォントスタイルを選択。
  ├ ② スタンプツールバーから好きな絵文字をタップして選択中状態にする。
  └ ③ 手帳（カード）上の好きな位置をタップすると、そこにペタッとスタンプが押されます！

【STEP 4】公開設定＆みんなと共有
  ├ 日記右上にある「🔒 非公開」または「🌐 公開中」のバッジをタップして公開状態を変更。
  └ 「みんなの誌」タブで他のユーザーの日記を読み、絵文字リアクション（❤️ 🌟 ☕ 🫂）を送りましょう！
```

## 🛠️ 技術スタック

- **フロントエンド**: React 18 / Vite / TypeScript / Tailwind CSS / Lucide Icons / Canvas-Confetti
- **バックエンド (サーバー)**: Express (Node.js) + Google GenAI SDK (`@google/genai`)
- **データベース & 認証**: Firebase Firestore / Firebase Authentication
- **AI モデル**: Google Gemini 2.5 Flash (`gemini-2.5-flash`)

## 🚀 開発環境のセットアップ

### 1. 依存パッケージのインストール
```bash
npm install
```

### 2. 環境変数の設定 (`.env.example` 参照)
`.env` ファイルを作成し、Gemini APIキーを設定します：
```env
GEMINI_API_KEY=your_gemini_api_key_here
```

### 3. 開発サーバーの起動
```bash
npm run dev
```
ブラウザで `http://localhost:3000` にアクセスします。
