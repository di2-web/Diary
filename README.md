# 📖 LifeLog AI Diary (手帳風AI日記 ＆ フレンド共有SNS)

**LifeLog AI Diary** は、日々の「つぶやき（写真・音声・テキスト・気分）」を投稿し、それらを束ねて **Gemini AI** が温かみのある手帳風日記を自動生成してくれるパーソナル ＆ 友達共有アプリケーションです。

---

## 🌟 主な機能と特徴

### 1. ✏️ つぶやき投稿 ＆ クイック入力
- ヘッダーやモバイルナビ中央の**鉛筆マーク（つぶやくボタン）**を押すと、いつでも即座につぶやき入力フォームへジャンプします。
- テキストだけでなく、**画像添付・音声メッセージ録音・気分（絵文字）**を一度に記録可能です。
- **共有カテゴリ選択**: 「Default」「All」「家族」「親友」など、投稿ごとに見せたい対象を柔軟に設定できます。

### 2. 🤖 Gemini AI 手帳日記の自動生成
- 1日に投稿した複数のつぶやきを AI が統合し、素敵な手帳風日記文章を自動執筆します。
- **選べるAIトーン**: 「ほのぼの」「文学的」「エネルギッシュ」「絵文字たっぷり」「落ち着いた口調」など、その日の気分に合わせて文言の雰囲気を変更できます。
- 日記は後から編集・清書したり、共有範囲を変更できます。

### 3. 🤝 友達追加 ＆ 招待リンク・QRコード
- **マイID ＆ ユーザー検索**: 表示名やマイIDを使って友達を検索・即時追加できます。
- **専用招待リンク ＆ QRコード**:
  - マイページから自分専用の**友達招待リンクをワンタップでコピー**できます。
  - **リアルタイム生成されるQRコード**を表示・保存でき、スマートフォンで読み込むだけで簡単に友達登録が可能です。
  - 招待URLからアクセスしたユーザーには画面上部に「友達招待バナー」が届き、ワンタップで相互追加できます。

### 4. 🏷️ 共有カテゴリ（Default / All / カスタム）
- 投稿を共有する範囲をカテゴリ単位でコントロールできます。
  - **`Default`**: 基本の共有枠。マイページで「Default」に振り分けた友達に届きます。
  - **`All`**: **登録済みのすべての友達**に届きます（※友達登録していない非友達には一切公開されません）。
  - **`カスタムカテゴリ`**: 「家族」「親友」「部活」など、マイページで自由に追加・友達への割り当てが可能です。

### 5. 💬 リアルタイム・絵文字リアクション ＆ コメント
- タイムラインの投稿に対して、標準の絵文字（❤️, 🌟, ☕, 🫂, 😊 など）に加え、**全絵文字ピッカー（＋ボタン）**からお好きな絵文字を選んでリアルタイムにリアクションできます。
- 友達との温かいコメントやり取りが楽しめます。

### 6. 📅 カレンダー閲覧 ＆ 検索・分析
- **カレンダー画面**: 日付ごとに投稿や日記を振り返ることができます。
- **キーワード検索**: 過去の出来事や感情を素早く検索できます。
- **気分の波**: 記録した気分のグラデーションや統計をグラフで可視化します。

## 📖 使い方ガイド

### 【投稿編】つぶやきを記録する
1. 画面右上またはモバイルナビ中央の**鉛筆アイコン「つぶやく」ボタン**をタップします。
2. いまの出来事や気持ちを入力し、必要に応じて写真や音声メモを添えます。
3. 共有カテゴリ（`Default`, `All`, または作成したカスタムカテゴリ）を選択して「投稿する」を押します。

### 【AI日記編】手帳日記を生成する
1. 「きょうの記録」画面の「✨ 日記を作成」ボタンを押します。
2. AI執筆の文体トーンを選んで「日記を生成する」をクリックします。
3. AIがつぶやきを整理し、手帳風のデザインで日記を完成させてくれます。

### 【友達追加編】招待リンク・QRコードでつながる
1. 「マイページ」タブを開き、「友達招待リンク ＆ QRコード」エリアを表示します。
2. 「リンクをコピー」または「QRコードを表示」を押して友達に共有します。
3. 友達一覧から、相手に「Default」「All」「家族」などのカテゴリチェックを入れてグループ分けできます。

## 🛠️ テクノロジー構成

- **フロントエンド**: React 18, TypeScript, Tailwind CSS, Lucide Icons, Motion

- **QRコード生成**: Dynamic QR Server API

## 💻 ローカル環境での動かし方（完全・初心者向けガイド）

GitHubからプロジェクトをダウンロードして、ご自身のパソコン（Windows / Mac）でアプリを動かすためのステップ・バイ・ステップ手順です。

---

### 1. 必要なソフトウェアのインストール（最初だけ）

まずは以下の2つの無料ソフトをインストールしてください。

1. **Node.js（必須）**
   - パソコン上で JavaScript / TypeScript を実行するために必要です。
   - [Node.js 公式サイト (https://nodejs.org/)](https://nodejs.org/) にアクセスし、**「LTS（推奨版）」** をダウンロードしてインストールしてください。
   - ※ インストール時、選択肢はすべてデフォルト（次へ）のままで大丈夫です。

2. **VS Code（推奨エディタ）**
   - コードの編集やコマンドの実行が簡単に行える人気の無料エディタです。
   - [Visual Studio Code 公式サイト](https://code.visualstudio.com/) からダウンロードしてインストールします。

---

### 2. ソースコードを自分のパソコンにダウンロードする

ダウンロード方法は **「A. ZIPファイルでダウンロード」** または **「B. Gitコマンドでクローン」** の好きな方を選べます。

#### 【方法A】ZIPファイルでダウンロードする場合（簡単！）
1. GitHubのページ右上にある緑色の **「<> Code」** ボタンをクリックします。
2. 出てきたメニューから **「Download ZIP」** を選択します。
3. ダウンロードされた ZIP ファイルを右クリックして「すべて展開（解凍）」します。
4. VS Code を開き、メニューの **[ファイル] ＞ [フォルダを開く]** から、解凍したフォルダ（`package.json` ファイルが入っている場所）を選択します。

#### 【方法B】Git（コマンド）でダウンロードする場合
1. ターミナル（Windowsなら PowerShell / Git Bash、Macなら ターミナル）を開きます。
2. 以下のコマンドを実行します：
   ```bash
   # 1. リポジトリをダウンロード
   git clone <あなたのGitHubリポジトリURL>

   # 2. ダウンロードしたフォルダの中に移動
   cd lifelog-ai-diary
   ```
3. そのまま `code .` と入力すると VS Code でフォルダが開きます。

---

### 3. VS Code でターミナルを開き、依存パッケージをインストールする

1. VS Code の画面上部メニューから **[ターミナル] ＞ [新しいターミナル]** をクリックします（画面下に黒いウィンドウが表示されます）。
2. 以下のコマンドを入力して **Enterキー** を押します：

   ```bash
   npm install
   ```

   ※ これにより、アプリに必要なライブラリ（React, Express, Tailwind CSS など）が自動的にダウンロードされます（1〜2分ほどかかります）。

---

### 4. APIキーの設定（.env ファイルの作成）

AIによる日記自動生成機能（Gemini API）を動かすためのキーを設定します。

1. **`.env` ファイルの作成**:
   - VS Code の左側ファイル一覧の何もない場所を右クリックし、**「新しいファイル」** を作成します。
   - ファイル名を **`.env`** と名付けます（※先頭にドット `.` が必要です）。
2. **APIキーの書き込み**:
   - 作成した `.env` ファイルの中に以下をコピー＆ペーストします：

   ```env
   GEMINI_API_KEY="ここにあなたのGemini_APIキーを貼り付け"
   ```

3. **Gemini APIキーの取得方法（完全無料）**:
   - [Google AI Studio (https://aistudio.google.com/)](https://aistudio.google.com/) にアクセスし、Googleアカウントでログインします。
   - **「Create API key」** ボタンを押し、発行された長い英数字の文字列（API Key）をコピーします。
   - `.env` ファイルの `" "` の中に貼り付けて保存（Ctrl + S / Cmd + S）してください。

---

### 5. 開発サーバーの起動 ＆ ブラウザで確認

1. VS Code のターミナルで以下のコマンドを実行します：

   ```bash
   npm run dev
   ```

2. ターミナルに以下のようなメッセージが表示されます：
   ```text
   Server running on http://localhost:3000
   ```

3. ブラウザ（ChromeやSafari等）を開き、アドレスバーに以下を入力してアクセスします：
   ```text
   http://localhost:3000
   ```

🎉 **これでローカル環境でのアプリ起動は完了です！**  
つぶやきの投稿、AI日記の生成、マイページの操作などを自分のパソコン上でお試しいただけます。

---

### 6. アプリの停止 ＆ 次回の起動方法

- **アプリを停止したいとき**: ターミナル画面を選択した状態で `Ctrl + C` キーを押すと停止します。
- **次回また起動したいとき**:
  1. VS Code でプロジェクトフォルダを開きます。
  2. ターミナルで `npm run dev` と入力して Enter キーを押すだけでOKです。

## 🚀 Netlify（ネットリファイ）へのデプロイ手順

本アプリは Netlify へのデプロイ（Web公開）に完全対応しています。設定ファイル（`netlify.toml`）およびサーバーレスAPI（`netlify/functions/api.ts`）を配置済みのため、数クリックで公開できます。

### 【方法A】GitHubと連携して自動デプロイする（一番おすすめ・簡単）

1. **GitHub にコードをプッシュする**:
   - 自分の GitHub アカウントに本リポジトリをコミット＆プッシュします。
2. **Netlify にサインイン**:
   - [Netlify (https://www.netlify.com/)](https://www.netlify.com/) にアクセスし、GitHub アカウントでログインします。
3. **新しいサイトを追加**:
   - **「Add new site」 ＞ 「Import an existing project」** を選択します。
   - 連携先サービスで **「GitHub」** を選び、このプロジェクトのリポジトリを選択します。
4. **ビルド設定の確認**:
   - `netlify.toml` があるため、ビルド設定（Build command: `npm run build` / Publish directory: `dist`）は自動認識されます。
5. **環境変数（`GEMINI_API_KEY`）の登録**:
   - デプロイ設定画面の **「Environment variables」**（またはサイト設定の `Site configuration > Environment variables`）を開きます。
   - `Key` に `GEMINI_API_KEY`、`Value` にご自身の Gemini API キーを入力します。
6. **「Deploy」を押す**:
   - 約1〜2分で自動ビルド＆公開が完了し、`https://xxxx.netlify.app` のURLで世界中に公開されます！

---

### 【方法B】Netlify CLI（コマンド）で手動デプロイする場合

```bash
# 1. Netlify CLI をグローバルインストール
npm install -g netlify-cli

# 2. Netlify にログイン
netlify login

# 3. 初回デプロイ・セットアップ
netlify init

# 4. 本番デプロイ
netlify deploy --build --prod
```

※ デプロイ完了後、Netlify ダッシュボードの `Site configuration > Environment variables` から `GEMINI_API_KEY` を設定してください。

### ❓ よくある質問・トラブルシューティング

- **Q. `npm: command not found` と出る**
  - Node.js がまだインストールされていないか、インストール後のターミナル再起動が必要です。Node.js をインストール後に VS Code を再起動してください。
- **Q. `Port 3000 is already in use` と出る**
  - すでに他のプログラムが 3000 番ポートを使っている可能性があります。ターミナルで一度 `Ctrl + C` を押して停止させるか、パソコンを再起動してみてください。
- **Q. AI日記生成でエラーが出る**
  - `.env` ファイルの `GEMINI_API_KEY` が正しいか確認してください（前後に余計なスペースが入っていないか、ダブルクォーテーションで囲まれているか）。`.env` を編集した後は `npm run dev` を一度停止（Ctrl+C）して再起動が必要です。
